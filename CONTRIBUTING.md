# Contribuindo

Obrigado pelo interesse em contribuir! 

## Como contribuir

1. **Fork** o repositório
2. **Clone** seu fork: `git clone https://github.com/seu-usuario/sharepoint-file-navigator`
3. **Crie uma branch** para sua feature: `git checkout -b feature/minha-feature`
4. **Faça suas mudanças** e commit: `git commit -m "Adiciona minha feature"`
5. **Push** para sua branch: `git push origin feature/minha-feature`
6. **Abra um Pull Request**

## Padrões

- Código em Python 3.8+
- PEP 8 para estilo de código
- Commits em português ou inglês, descritivos
- Adicione testes para novas features

## Reportando Bugs

Abra uma [Issue](https://github.com/usuario/sharepoint-file-navigator/issues) descrevendo:
- Comportamento esperado
- Comportamento atual
- Passos para reproduzir
- Versão do Python
- SO (Windows/Mac/Linux)

## Sugestões de Features

Abra uma [Discussion](https://github.com/usuario/sharepoint-file-navigator/discussions) descrevendo sua ideia!

Obrigado! 🎉
