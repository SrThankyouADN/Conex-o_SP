Leitor de Arquivo SharePoint

Cole aqui o link compartilhado do arquivo XLSX do SharePoint

Como obter o link do arquivo:

  1. Abra o SharePoint e navegue até o arquivo
  2. Clique com o botão direito no arquivo → Compartilhar
  3. Configure para que o link seja acessível
  4. Copie a URL do arquivo
  5. Cole aqui no campo acima
